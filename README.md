# Dúotec - Servicio Técnico y Refrigeración

## Descripción

Dúotec es un sitio web desarrollado para el emprendimiento de Pablo, dedicado al servicio técnico y la refrigeración. Su objetivo es presentar los servicios ofrecidos, las localidades de cobertura y proporcionar un medio de contacto para realizar consultas de manera sencilla y accesible para todo el público.

El sitio cuenta con tres páginas principales:

- **Inicio:** Presentación del emprendimiento y carrusel de imágenes de trabajos realizados.
- **Servicios y Cobertura:** información sobre los servicios disponibles y las localidades donde se trabaja.
- **Contacto:** formulario interactivo para preparar consultas y enviarlas mediante WhatsApp.

## Recursos utilizados
